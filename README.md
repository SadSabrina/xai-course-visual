# xai-course-visual

Интерактивные визуализации для курса по интерпретируемости (XAI).
Странички публикуются через GitHub Pages и встраиваются в шаги Stepik через `<iframe>`.

## Демки
- [density.html](density.html) — плотность точек двух кластеров: слайдер 0→1 сжимает облака (площадь↓ → плотность↑).
- [dense-region.html](dense-region.html) — «плотная область»: перетаскиваемый плотный сгусток на редком поле точек.
